
# 💻 Talent-IQ — AI-Powered Coding & Interview Platform

Talent-IQ is a web application designed to support coding practice, collaborative sessions, and technical interview preparation through an interactive development environment.

##  Live Demo

🔗 **[Visit Talent-IQ](https://talent-iq-1-148b.onrender.com/)**

##  Key Features

-  User Authentication & Management
-  Interactive Coding Environment
-  Code Execution using OneCompiler API 
-  Collaborative Coding Sessions
-  Real-Time Video & Communication 
-  Session Management
-  Background Job Processing 

## 🛠️ Tech Stack

- **Frontend:**React.js, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** MongoDB, Mongoose
- **Authentication:** Clerk 
- **Real-Time Communication:** Stream 
- **Background Jobs:** Inngest 
- **Code Execution:** OneCompiler API 
- **Cloud Database:** MongoDB Atlas
- **Deployment:** Render
